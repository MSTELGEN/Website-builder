# ManyRituals Funnel — File Guide

This folder contains the complete content layer for the ManyRituals digital product funnel. Everything is ready to paste, upload, or send. You handle deployment; this folder handles every word.

---

## Files

### `7-night-reset.md`
The free lead magnet in Markdown format. 10 sections (cover + 7 days + intro + close). Use this as the source of truth for content edits.

### `7-night-reset.html`
The same 10-page guide rendered as a fully styled HTML file. Open in any browser and use **Print → Save as PDF** to generate the final PDF. Fonts load from Google Fonts — requires internet connection to render correctly.

### `landing-page.html`
The email capture landing page. Paste into Carrd, Gumroad, or host directly. Replace `<!-- PDF MOCKUP HERE -->` with your actual PDF cover image. Wire the form to ConvertKit or your email platform.

### `email-sequence.md`
Five complete emails for your welcome sequence. Load into ConvertKit as an automation. Send times are noted at the top of each email.

### `19-euro-product-outline.md`
Full table of contents + chapter outlines for the €19 paid Sleep Reset Guide. Use this to write the full product or brief a writer.

### `bio-and-listings.md`
Platform bios, Gumroad product copy, and Stan Store/Carrd alternative copy. Ready to paste.

### `new-dm-template.md`
DM template for viewers who comment SLEEP on posts. Includes full version and short fallback. Replace `[POST_TOPIC]` and `[LANDING_PAGE_URL]` before sending.

